# Student Registration System

A simple Student Registration System built with **PHP & MySQL**.

### Features

* Add, edit, and delete students
* Search students
* Form validation
* Pagination
* AJAX

### Technologies

* PHP
* MySQL
* JavaScript / jQuery
* Bootstrap
* SweetAlert2
